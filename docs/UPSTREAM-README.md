# Upstream provenance

YouCraft is an independent video-player fork of FilmCraft by the ArtCraft team.
The imported source baseline is commit `fed0f42fd52012a337d744743a93409c0b1e8f9d`.

The original README is available in the [upstream source snapshot](https://github.com/storytold/filmcraft/blob/fed0f42fd52012a337d744743a93409c0b1e8f9d/README.md).
Its editor features, release downloads, branding, and support channels describe upstream FilmCraft,
not this fork. The duplicate local copy was replaced with this reference to avoid stale instructions
and links to removed brand assets.

For this fork, start with the [YouCraft README](../README.md) and [documentation index](README.md).
Internal `filmcraft-*` package names and `.fcproj` formats remain for compatibility.
Original [MIT](../LICENSE-MIT), [Apache-2.0](../LICENSE-APACHE), and [NOTICE](../NOTICE)
files are retained; asset credits remain in [ATTRIBUTION.md](../ATTRIBUTION.md).
